# Code of conduct

Be respectful and keep discussion about the work. Disagree with the code or the idea, not the person.

Harassment, personal attacks and discriminatory language are not welcome in issues, pull requests or any other project space. The maintainer may edit or remove contributions, and block participants, that break this.

To report a problem, email the address on the maintainer's GitHub profile, or use a private security advisory if it also involves a vulnerability (see [SECURITY.md](SECURITY.md)).
